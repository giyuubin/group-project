# 악성코드 예측 모델
## 1. 개요
### 1.1 프로젝트 정의
- 본 프로젝트는 Windows 실행 파일(.exe)의 PE(Portable Executable) 구조 내에서 파일의 직접적인 실행 없이 API 호출 패턴을 정적으로 추출하고, 이를 학습한 LightGBM 기계학습 모델을 통해 악성 여부를 사전 판별 및 차단하는 자동화 방어 파이프라인 구축을 목표로 한다.
### 1.2 기존 보안 시스템과의 차별점 및 한계 극복
- 서명 기반(Signature-based) 탐지의 한계 극복: 전통적인 백신이 사용하는 해시 서명 방식은 기수집된 데이터에만 의존하므로, 코드의 형태를 매번 바꾸는 다형성(Polymorphic) 멀웨어나 알려지지 않은 제로데이(Zero-Day) 공격에 무력하다.
- 동적 분석(Dynamic Analysis)의 자원 및 우회 한계 극복: 샌드박스(Sandbox) 환경의 동적 분석은 정밀하지만 가상 환경을 감지하여 행위를 멈추는 가상화 우회 멀웨어에 취약하며, 무거운 에뮬레이션 리소스를 소모한다. 본 정적 분석 모델은 파일을 실행하지 않으므로 안전하며, 밀리초(ms) 단위의 고속 탐지가 가능하다.
## 2. 연구 배경 및 목적
### 2.1 연구 배경
- 최근 멀웨어 공급망 공격 및 MaaS(Malware-as-a-Service)의 대중화로 인해 하루에도 수십만 개의 신종 위협 바이너리가 유포되고 있다. 파일 시스템 내부로 악성 코드가 진입하는 첫 관문(Initial Access)에서 위협을 선제적으로 차단하기 위한 경량화된 엔드포인트 정적 진단 기술이 필수적이다. // 내용 수정 했습니다.
### 2.2 위협 모델 정의
- 공격 대상 시스템: Windows OS 기반 엔드포인트 시스템 및 사용자 자산.
- 공격자 프로파일 및 시나리오: 사용자 시스템에 최초 침투하여 권한 상승, 자격 증명 탈취, 데이터 암호화 및 유출을 시도하는 주요 악성 패밀리.
  - Ransomware
  - Infostealer
  - RAT/Loader
## 3. 관련 연구 및 선행 연구
### 3.1 다른 PE 기반 분류 접근법과의 비교
- 바이너리 이미지화 기반 딥러닝 (CNN): 전체 바이트를 2D 이미지로 변환. 더미 데이터에 의해 픽셀이 왜곡되며, 의사결정 과정 해석이 불가함(Black-box).
- 행위 기반 동적 샌드박싱 모델: 실행 후 API 시퀀스 모니터링. 샌드박스 우회 기법(Sleep 등)을 탑재한 최신 멀웨어에 무력화됨.
### 3.2 본 프로젝트가 IAT 기반 정적 분석을 택한 이유
- 보안 도메인 지식과의 직접적 연계 (Explainability): PE 파일의 IAT(Import Address Table)는 실행 파일이 운영체제 커널의 기능을 호출하기 위해 선언한 윈도우 API들의 이정표이다. API 이름 자체가 파일의 '의도된 행위'를 정량적으로 대변하므로 투명하게 해석(XAI)할 수 있다. // 시스템 보안에서 배워서..
- 일관된 파이프라인 구조: 추출 로직이 가볍고 정형화되어 있어, 모델 학습 시 파싱 로직을 실시간 웹 백엔드 추론 엔진에 단 한 줄의 왜곡 없이 그대로 재사용할 수 있다.
## 4. 데이터셋
### 4.1 출처 및 수집 방법
- 원천 출처: Kaggle 플랫폼에 공개된 멀웨어 정적 분석용 대규모 윈도우 실행 파일 API 임포트 데이터셋.
- 표본의 다양성: VirusShare, VXHeaven 등의 글로벌 멀웨어 공유 인프라에서 수집된 실제 위협 샘플들과 클린 환경의 정상 유틸리티가 포함됨.
- 레이블 신뢰도: 각 샘플의 악성/정상 라벨은 글로벌 다중 백신 검증 엔진인 VirusTotal의 교차 검증 점수를 기반으로 하여 학술적 신뢰도가 보장됨.
